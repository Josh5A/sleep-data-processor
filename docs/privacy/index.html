Privacy

What this server sees, what it never sees, and who owns the spreadsheet.

Last updated September 15, 2026

What this server sees

The site is hosted on GitHub Pages. When your browser requests a page, GitHub logs the IP address the request came from and stores it for security purposes. This happens for every visitor, signed in to GitHub or not. Those logs are GitHub’s, held under the GitHub Privacy Statement; GitHub does not pass them on to whoever runs a Pages site, so no one here sees them.

Nothing else is collected. There is no account and no sign-in. No cookies are set. There are no analytics.

What it doesn’t see

This server never sees:

  • — Your sleep data. The file you choose, or drop, or paste is read by your own browser and converted there. It is never sent anywhere.
  • — The rows the tool produces. They exist in the page in front of you until you close the tab.
  • — Anything you do afterwards. Once you copy the rows, pasting them into Google Sheets is between you and Google.

The Sheet is yours

The template link makes a copy of a spreadsheet in your own Google account. It is your document. Nobody here can open it, and nobody here is told that you made it.

If you would rather not involve Google at all, the rows are ordinary tab-separated text. You can paste them into any spreadsheet you choose.
